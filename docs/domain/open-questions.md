# Open questions

Questions for the owner. "Default we used" is what the kickstart specs follow until the owner answers. "Blocks?" is yes when the slice can't be built correctly without an answer; none blocks the kickstart, but four block go-live (Q-10, Q-24, Q-33, Q-34).

Source tags: `[pack: <file>#<id or heading>]`, `[brief]`, `[lead decision]`, `[assumption]`.
